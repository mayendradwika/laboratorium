# Instalasi Microsoft Office & Microsoft Access

Microsoft Office adalah paket aplikasi perkantoran yang paling populer di dunia, mencakup Word (pengolah kata), Excel (spreadsheet), PowerPoint (presentasi), dan Access (database management). Panduan ini akan membantu Anda memasang Microsoft Office beserta Microsoft Access menggunakan dua metode yang berbeda.

:::info

Microsoft Access Microsoft Access adalah aplikasi database management system (DBMS) yang termasuk dalam paket Microsoft Office versi Professional atau Pro Plus. Jika Anda memerlukan Access untuk praktikum database, pastikan memilih versi Office yang sudah menyertakan Access.
:::

---

## Metode 1: Menggunakan File Installer Lokal

Metode ini cocok digunakan untuk instalasi di komputer laboratorium yang sudah memiliki file installer Office tersimpan di server lokal atau hard disk.

### Tahap 1: Persiapan File Installer

Pastikan Anda memiliki folder installer Microsoft Office yang biasanya berisi:
- Folder **Office** dengan subfolder di dalamnya
- File **autorun.exe** atau **setup.exe**

### Tahap 2: Menjalankan Installer

1. Buka folder **Office** yang berisi file installer.
2. Masuk ke subfolder **Office** di dalamnya (biasanya ada struktur folder Office → Office).
3. Cari dan jalankan file **autorun.exe** dengan cara klik dua kali.

:::tip

Jika autorun.exe Tidak Ditemukan Jika tidak ada file autorun.exe, cari file **setup.exe** di dalam folder tersebut dan jalankan sebagai Administrator (klik kanan → Run as administrator).
:::

### Tahap 3: Memilih Versi Office

1. Setelah **autorun.exe** dijalankan, jendela **Installation Office** akan muncul.
2. Anda akan melihat beberapa pilihan versi Office yang tersedia, seperti:
   - **Office Professional Plus** (termasuk Access, Publisher, dan semua aplikasi)
   - **Office Standard** (hanya aplikasi dasar: Word, Excel, PowerPoint)
   - **Office Home & Business**
3. Pilih versi **Office Professional Plus** atau versi yang sudah menyertakan **Microsoft Access**.

:::warning

Pastikan Pilih Versi yang Tepat Jika Anda memerlukan Microsoft Access untuk praktikum database, jangan pilih versi Home atau Standard karena tidak menyertakan aplikasi Access. Pilih versi **Professional Plus** atau **Pro Plus**.
:::

### Tahap 4: Memulai Instalasi

1. Setelah memilih versi Office, klik tombol **Start Installation** atau **Install**.
2. Proses instalasi akan dimulai secara otomatis.
3. Tunggu hingga proses selesai (biasanya memakan waktu 10-30 menit tergantung kecepatan komputer dan versi Office yang diinstal).

### Tahap 5: Menyelesaikan Instalasi

1. Setelah instalasi selesai, akan muncul notifikasi bahwa Office berhasil terpasang.
2. Klik **Close** atau **Finish**.
3. Coba jalankan aplikasi Office seperti **Word**, **Excel**, atau **Access** dari menu Start untuk memastikan instalasi berhasil.

:::tip

Aktivasi Office Setelah instalasi, Office mungkin meminta aktivasi. Lihat tutorial **Aktivasi Microsoft Office** (file terpisah) untuk panduan aktivasi lengkap.
:::

## Metode 2: Menggunakan Website Massgrave

Metode ini menggunakan tools dari website Massgrave yang menyediakan installer Office resmi dari Microsoft dengan berbagai versi dan komponen yang dapat dipilih sesuai kebutuhan.

### Tahap 1: Mengakses Website Massgrave

1. Buka browser favorit Anda (Chrome, Firefox, Edge, dll.).
2. Ketik alamat berikut di address bar:
   ```
   https://massgrave.dev/
   ```
3. Tekan **Enter** untuk membuka website.

:::info

Apa itu Massgrave? Massgrave adalah website yang menyediakan tools dan panduan untuk mengunduh serta menginstal produk Microsoft secara legal dari server resmi Microsoft. Website ini sangat berguna untuk mendapatkan installer Office terbaru tanpa harus mencari dari sumber tidak jelas.
:::

### Tahap 2: Masuk ke Menu Download

1. Setelah website terbuka, cari dan klik menu **Download Windows/Office** di halaman utama.
2. Anda akan dibawa ke halaman yang berisi berbagai tools dan link download untuk Windows dan Office.

### Tahap 3: Pilih Office C2R Installer

1. Scroll ke bawah hingga menemukan bagian **Office C2R Installer** atau **Office Deployment Tool**.
2. Klik link download untuk **Office C2R Installer**.

:::info

Apa itu C2R? C2R (Click-to-Run) adalah teknologi instalasi Office modern dari Microsoft yang memungkinkan download dan instalasi berjalan secara bersamaan, sehingga lebih cepat dan efisien.
:::

### Tahap 4: Download Installer Access atau Office

1. Setelah masuk ke halaman Office C2R Installer, Anda akan melihat berbagai opsi versi Office yang tersedia.
2. Pilih salah satu dari opsi berikut:
   - **Office Professional Plus** (termasuk Access dan semua aplikasi Office)
   - **Microsoft Access** (jika hanya ingin menginstal Access saja)
   - **Office 2021** atau **Office 2019** (sesuai kebutuhan)
3. Klik link download yang sesuai.
4. File installer akan diunduh ke komputer Anda (biasanya berukuran beberapa MB hingga beberapa ratus MB tergantung versi yang dipilih).

### Tahap 5: Menjalankan Installer

1. Setelah download selesai, buka folder **Downloads** di File Explorer.
2. Cari file installer yang baru saja diunduh (biasanya bernama **OfficeSetup.exe** atau sejenisnya).
3. Klik dua kali pada file installer untuk menjalankannya.
4. Jika muncul dialog **User Account Control (UAC)**, klik **Yes** untuk memberikan izin.

### Tahap 6: Proses Instalasi

1. Installer akan mulai mengunduh file Office dari server Microsoft secara otomatis.
2. Proses instalasi berjalan secara online, artinya komputer harus terhubung ke internet selama proses berlangsung.
3. Tunggu hingga proses download dan instalasi selesai (biasanya memakan waktu 15-45 menit tergantung kecepatan internet).
4. Setelah selesai, Office akan terpasang secara otomatis tanpa perlu konfigurasi tambahan.

### Tahap 7: Verifikasi Instalasi

1. Buka menu Start Windows.
2. Cari aplikasi **Word**, **Excel**, **PowerPoint**, atau **Access**.
3. Jalankan salah satu aplikasi untuk memastikan instalasi berhasil.
4. Jika aplikasi terbuka dengan normal, berarti instalasi telah selesai.

## Perbandingan Kedua Metode

| Aspek | Metode 1 (Installer Lokal) | Metode 2 (Massgrave) |
|---|---|---|
| **Koneksi Internet** | Tidak perlu internet setelah file tersedia | Wajib ada koneksi internet stabil |
| **Kecepatan** | Lebih cepat jika file sudah ada | Tergantung kecepatan internet |
| **Versi Office** | Tergantung file installer yang tersedia | Bisa memilih versi terbaru dari Microsoft |
| **Ukuran Download** | File besar harus disimpan di server/HDD | Download langsung, tidak perlu simpan installer besar |
| **Cocok untuk** | Instalasi massal di lab tanpa internet | Instalasi individual dengan internet |

## Tips Setelah Instalasi

Setelah Microsoft Office berhasil terpasang, berikut beberapa tips untuk memaksimalkan penggunaannya:

### 1. Aktivasi Office

- Office perlu diaktivasi agar dapat digunakan tanpa batas waktu.
- Lihat tutorial terpisah tentang **Aktivasi Microsoft Office** untuk panduan lengkap.

### 2. Update Office

- Pastikan Office selalu up-to-date untuk mendapatkan fitur terbaru dan patch keamanan.
- Buka salah satu aplikasi Office → **File → Account → Update Options → Update Now**.

### 3. Konfigurasi Awal

- Saat pertama kali membuka aplikasi Office, Anda akan diminta untuk sign in dengan akun Microsoft.
- Anda bisa skip langkah ini jika tidak memerlukan sinkronisasi cloud.

### 4. Install Template Tambahan

- Office menyediakan banyak template gratis untuk Word, Excel, dan PowerPoint.
- Akses template melalui **File → New → Search for online templates**.

## Troubleshooting Umum

| Masalah | Penyebab | Solusi |
|---|---|---|
| Installer tidak bisa dibuka | File corrupt atau tidak lengkap | Download ulang installer atau gunakan file dari sumber lain |
| Error "Another version of Office is installed" | Office versi lama masih terpasang | Uninstall Office versi lama melalui Control Panel terlebih dahulu |
| Instalasi terhenti di tengah jalan | Koneksi internet terputus (Metode 2) | Pastikan koneksi internet stabil atau gunakan Metode 1 |
| Microsoft Access tidak muncul | Versi Office yang diinstal tidak menyertakan Access | Uninstall Office dan instal ulang versi Professional Plus |
| Office meminta aktivasi terus-menerus | Lisensi belum aktif atau expired | Gunakan tool aktivasi yang tepat (lihat tutorial aktivasi) |

## Cara Mengecek Versi Office yang Terinstal

Untuk memastikan versi Office dan aplikasi apa saja yang terpasang:

1. Buka salah satu aplikasi Office (misalnya **Word**).
2. Klik menu **File** di pojok kiri atas.
3. Pilih **Account** di bagian bawah menu sebelah kiri.
4. Di bagian **Product Information**, Anda akan melihat:
   - Nama produk (contoh: Microsoft Office Professional Plus 2021)
   - Status aktivasi
   - Versi dan build number

Jika Microsoft Access tidak terlihat di menu Start, kemungkinan versi Office yang terinstal tidak menyertakan Access.
