# Instalasi MATLAB R2021a

MATLAB (Matrix Laboratory) adalah software komputasi numerik yang sangat powerful untuk analisis data, pemrograman, visualisasi, dan pemrosesan sinyal. Software ini banyak digunakan di bidang teknik, matematika, fisika, dan penelitian ilmiah.

Panduan ini akan membantu Anda memasang MATLAB R2021a di komputer Windows beserta proses aktivasi menggunakan crack.

:::warning

Tutorial ini untuk tujuan edukasi dan pembelajaran di lingkungan akademis. Untuk penggunaan profesional atau komersial, beli lisensi resmi dari MathWorks di [mathworks.com](https://www.mathworks.com/).
:::

## Persiapan Sebelum Instalasi

### 1. Matikan Antivirus

Antivirus akan mendeteksi file crack sebagai ancaman dan menghapusnya otomatis.

**Cara menonaktifkan Windows Defender:**
1. Buka **Windows Security** dari Start Menu
2. Pilih **Virus & threat protection**
3. Klik **Manage settings**
4. Nonaktifkan **Real-time protection**

:::danger

Penting Aktifkan kembali antivirus setelah instalasi dan aktivasi selesai.
:::

### 2. Persyaratan Sistem

- Windows 10/11 64-bit
- RAM minimal 4 GB (disarankan 8 GB)
- Storage minimal 20 GB tersedia
- Processor dengan dukungan SSE2

## Tahap 1: Extract File Installer

1. Cari file installer MATLAB R2021a (biasanya dalam format `.rar` atau `.zip`).
2. Klik kanan pada semua file archive MATLAB, lalu pilih **Extract Here**.
3. Tunggu proses ekstraksi selesai hingga muncul folder **MATLAB R2021a** atau sejenisnya.
4. Buka folder hasil ekstraksi.



:::info

Pastikan ekstrak semua file archive MATLAB yang ada (biasanya ada beberapa part jika file besar).
:::

---

## Tahap 2: Jalankan Setup Installer

### 1. Buka Folder Installer

- Di dalam folder hasil ekstraksi, cari folder atau file bernama **Matlab910R2021a_Win64** atau **setup.exe**.
- Buka folder tersebut jika berbentuk folder.

### 2. Jalankan Setup

- Cari dan klik dua kali pada file **setup.exe**.
- Jika muncul dialog **User Account Control (UAC)**, klik **Yes**.

### 3. Pilih Opsi Instalasi

Pada wizard instalasi yang muncul:
- Jika muncul pilihan **"Install manually without using the internet"**, pilih opsi tersebut.
- Klik **Yes** atau **Next** untuk melanjutkan.

### 4. Terima License Agreement

- Pada halaman **License Agreement**, klik **Yes** atau centang **"I accept the terms of the license agreement"**.
- Klik **Next**.

## Tahap 3: Memasukkan License Key

### 1. Ambil Folder License dari Ekstraksi

- Kembali ke folder hasil ekstraksi MATLAB.
- Cari folder bernama **Crack**, **License**, **Jamu**, atau **Readme**.
- Buka folder tersebut dan cari file **readme.txt** atau file teks berisi **license key**.

### 2. Salin License Key

- Buka file readme atau file license.
- Anda akan melihat deretan kode license key (biasanya format angka-huruf panjang).
- Blok dan salin (copy) license key tersebut dengan `Ctrl + C`.

### 3. Masukkan ke Installer

- Kembali ke jendela installer MATLAB.
- Paste license key yang sudah disalin ke kolom **"File Installation Key"**.
- Klik **Next**.

### 4. Pilih License File

- Pada halaman berikutnya, pilih opsi **"Browse for license file"** atau **"Select license file"**.
- Klik tombol **Browse**.
- Navigasi ke folder **Crack** atau **Jamu** dari hasil ekstraksi MATLAB.
- Cari file bernama **license.lic** atau **matlab.lic**.
- Pilih file tersebut dan klik **Open**.
- Klik **Next**.

## Tahap 4: Pilih Lokasi Instalasi

### 1. Tentukan Drive Instalasi

Anda bisa memilih menginstal MATLAB di drive C atau D:

**Untuk Drive C (Default):**
- Biarkan path default:
  ```
  C:\Program Files\MATLAB\R2021a
  ```

**Untuk Drive D (Jika C penuh):**
- Klik tombol **Browse** pada path instalasi.
- Navigasi ke **D:\**
- Buat folder baru bernama **MATLAB** (klik kanan → New → Folder).
- Pilih folder tersebut.
- Path akan menjadi: `D:\MATLAB\R2021a`

### 2. Pilih Komponen

- Pada halaman **Select Products**, Anda akan melihat daftar toolbox MATLAB.
- **Hapus centang** pada **MATLAB Parallel Server** jika tidak diperlukan (untuk menghemat ruang dan waktu instalasi).
- Biarkan komponen penting lainnya tetap tercentang.
- Klik **Next**.

### 3. Opsi Shortcut

- Pada halaman **Select Options**, centang **"Add shortcut to desktop"** jika ingin shortcut di Desktop.
- Klik **Next**.

---

## Tahap 5: Mulai Instalasi

1. Review semua pengaturan pada halaman **Confirm Selections**.
2. Klik **Begin Install** untuk memulai proses instalasi.
3. Tunggu proses instalasi selesai (biasanya 15-45 menit tergantung kecepatan komputer dan komponen yang dipilih).

:::info

Proses Berjalan Selama instalasi berlangsung, jangan matikan komputer atau menutup installer. Anda bisa meminimalkan jendela installer dan menggunakan komputer untuk hal lain sambil menunggu.
:::

## Tahap 6: Apply Crack (Aktivasi)

Setelah instalasi selesai, jangan langsung membuka MATLAB. Kita perlu menerapkan crack terlebih dahulu.

### 1. Jangan Buka MATLAB Dulu

- Ketika instalasi selesai, **jangan centang** opsi **"Launch MATLAB"**.
- Klik **Finish** atau **Close** untuk menutup installer.

### 2. Navigasi ke Folder Crack Target

Sekarang kita perlu menemukan folder tempat file crack akan ditimpa. Lokasi folder tergantung di mana Anda menginstal MATLAB:

**Jika Install di C:**
```
C:\Program Files\MATLAB\R2021a\bin\win64\matlab-startup-plugins\lmgrimpl
```

**Jika Install di D:**
```
D:\MATLAB\R2021a\bin\win64\matlab-startup-plugins\lmgrimpl
```

**Cara mencapai folder tersebut:**
1. Buka **File Explorer** (`Windows + E`)
2. Buka drive C atau D (sesuai lokasi instalasi)
3. Masuk ke **Program Files** → **MATLAB** → **R2021a** → **bin** → **win64** → **matlab-startup-plugins** → **lmgrimpl**

### 3. Salin File Crack

- Kembali ke folder hasil ekstraksi MATLAB.
- Buka folder **Crack** atau **Jamu**.
- Cari file bernama **libmwlmgrimpl.dll**.
- Klik kanan pada file tersebut dan pilih **Copy** (`Ctrl + C`).

### 4. Timpa File Original

- Kembali ke folder **lmgrimpl** yang sudah dibuka sebelumnya.
- **Paste** file crack ke folder tersebut (`Ctrl + V`).
- Akan muncul dialog **"Replace or Skip Files"** karena sudah ada file dengan nama sama.
- Pilih **Copy and Replace** atau **Replace the file in the destination**.
- Jika muncul permintaan Administrator, klik **Continue** atau **Yes**.

File crack kini telah menggantikan file original, dan MATLAB teraktivasi secara permanen.

## Tahap 7: Menjalankan dan Menguji MATLAB

### 1. Buka MATLAB

- Cari **MATLAB R2021a** dari menu Start Windows.
- Klik untuk membuka aplikasi.
- Tunggu beberapa saat hingga MATLAB terbuka (first launch biasanya lebih lama).

### 2. Verifikasi Aktivasi

Jika MATLAB terbuka tanpa meminta aktivasi atau login, berarti crack berhasil diterapkan.

### 3. Test Sederhana

Coba jalankan perintah sederhana di Command Window:
```matlab
>> a = [1 2 3; 4 5 6; 7 8 9]
>> det(a)
```

Jika muncul hasil perhitungan tanpa error, instalasi berhasil.

## Troubleshooting Umum

| Masalah | Penyebab | Solusi |
|---|---|---|
| File crack terhapus saat ekstraksi | Antivirus menghapus otomatis | Matikan antivirus sebelum ekstraksi, download ulang jika perlu |
| MATLAB meminta aktivasi saat dibuka | Crack belum diterapkan atau salah folder | Pastikan file libmwlmgrimpl.dll ditimpa di folder lmgrimpl yang benar |
| Error "License Manager Error" | License file salah atau tidak ditemukan | Gunakan license.lic yang sesuai dengan versi R2021a dari folder crack |
| Instalasi gagal di tengah jalan | Ruang disk tidak cukup atau file corrupt | Pastikan minimal 20 GB tersedia, re-extract file installer |
| MATLAB sangat lambat | RAM tidak cukup atau terlalu banyak toolbox | Tutup aplikasi lain, atau reinstall dengan toolbox minimal |

## Tips Penggunaan MATLAB

### 1. Set Current Folder

Sebelum bekerja, set **Current Folder** ke lokasi project Anda agar file .m dapat dijalankan dengan mudah.

### 2. Gunakan Help Documentation

MATLAB memiliki dokumentasi yang sangat lengkap. Ketik `doc namaFungsi` untuk membuka help.

### 3. Simpan Workspace

Gunakan perintah `save('namafile.mat')` untuk menyimpan semua variabel, dan `load('namafile.mat')` untuk memuat kembali.

### 4. Matikan Update Otomatis

Agar crack tidak terganggu, matikan update otomatis di **Preferences → MATLAB → General**.
