# Instalasi Adobe Photoshop CS6

Adobe Photoshop CS6 adalah salah satu versi paling legendaris dari software editing foto dan desain grafis profesional. Meskipun sudah ada versi yang lebih baru (Creative Cloud), CS6 masih banyak digunakan karena stabilitas, performa ringan, dan tidak memerlukan langganan bulanan seperti Adobe Creative Cloud.

Panduan ini akan membantu Anda memasang Adobe Photoshop CS6 di komputer Windows, termasuk cara aktivasi menggunakan crack dan memblokir koneksi firewall untuk mencegah validasi lisensi online.

## Persiapan Sebelum Instalasi

Sebelum memulai proses instalasi, pastikan hal-hal berikut sudah siap:

### 1. File Installer dan Crack

Anda memerlukan:
- **File installer Adobe Photoshop CS6** (biasanya berupa folder atau file `.exe`)
- **File crack** berupa `amtlib.dll` (biasanya tersimpan dalam folder bernama "Crack" atau "SN.CS6.NesabaMedia")

Pastikan file-file tersebut sudah diekstrak dan siap digunakan.

### 2. Nonaktifkan Antivirus

Program antivirus sering mendeteksi file crack sebagai ancaman (*false positive*) dan akan menghapus atau memblokir file tersebut secara otomatis.

:::danger

Penting: Matikan Antivirus Sementara Sebelum memulai instalasi: 1. Buka aplikasi antivirus Anda (Windows Defender, Avast, AVG, Kaspersky, dll.) 2. Nonaktifkan **Real-time Protection** atau **Shield** sementara 3. Lanjutkan proses instalasi 4. **Jangan lupa aktifkan kembali** antivirus setelah instalasi selesai
:::

## Tahap 1: Menjalankan Installer Photoshop CS6

Setelah persiapan selesai, saatnya memulai proses instalasi.

### 1. Jalankan Setup.exe

- Buka folder installer Adobe Photoshop CS6.
- Cari file bernama **Set-up.exe** atau **Setup.exe**.
- Klik kanan pada file tersebut dan pilih **"Run as administrator"** untuk menghindari masalah perizinan.


### 2. Pilih "Try" (Uji Coba)

- Jendela installer Adobe akan terbuka.
- Ketika diminta untuk memasukkan Serial Number atau memilih opsi instalasi, pilih **"Try"** atau **"Install Trial"** untuk melanjutkan dengan versi uji coba 30 hari.
- Jangan khawatir, Anda akan mengaktifkannya secara permanen menggunakan crack setelah instalasi selesai.


:::tip

Kenapa Pilih "Try"? Memilih opsi "Try" memungkinkan installer berjalan tanpa harus memasukkan serial number yang valid. Setelah instalasi, crack akan menggantikan file validasi lisensi sehingga Photoshop bisa digunakan tanpa batas waktu.
:::

### 3. Accept License Agreement

- Baca (atau lewati) syarat dan ketentuan lisensi Adobe.
- Klik **"Accept"** untuk menyetujui dan melanjutkan.

## Tahap 2: Memilih Komponen Instalasi

Pada tahap ini, Anda akan memilih komponen Photoshop yang akan diinstal.

### 1. Pilih Hanya "Adobe Photoshop CS6 (64 bit)"

- Pada daftar komponen yang tersedia, **hanya centang** opsi **Adobe Photoshop CS6 (64 bit)**.
- **Jangan centang** komponen lain seperti:
  - Adobe Bridge CS6
  - Adobe ExtendScript Toolkit
  - Adobe Extension Manager
  - Camera Raw (kecuali Anda memerlukan fitur ini untuk editing foto RAW)

Memilih hanya komponen utama akan mempercepat instalasi dan mengurangi ukuran aplikasi yang terpasang.


:::info

Mengapa Hanya 64-bit? Versi 64-bit Photoshop CS6 dapat memanfaatkan RAM lebih dari 4 GB, sehingga jauh lebih cepat dan stabil untuk editing file besar dibanding versi 32-bit. Pastikan sistem operasi Anda juga Windows 64-bit.
:::

### 2. Klik Install

- Setelah memilih komponen, klik tombol **"Install"** untuk memulai proses instalasi.
- Tunggu proses instalasi selesai (biasanya memakan waktu 5-15 menit tergantung kecepatan hard disk).


### 3. Klik Close Setelah Selesai

- Setelah instalasi selesai, akan muncul notifikasi bahwa Photoshop CS6 telah terpasang.
- Klik **"Close"** untuk menutup jendela installer.

:::warning

Jangan Buka Photoshop Dulu Jangan langsung membuka Photoshop CS6 setelah instalasi selesai. Anda perlu menerapkan crack terlebih dahulu agar aplikasi dapat digunakan tanpa batas waktu uji coba.
:::

## Tahap 3: Menerapkan Crack (amtlib.dll)

Tahap ini adalah yang paling penting untuk mengaktifkan Photoshop CS6 secara permanen.

### 1. Buka Folder Crack

- Buka folder crack yang biasanya bernama **SN.CS6.NesabaMedia** atau **Crack**.
- Di dalam folder tersebut, cari subfolder bernama **Crack** → **64bit**.
- Anda akan menemukan file bernama **amtlib.dll**.


### 2. Salin File amtlib.dll

- Klik kanan pada file **amtlib.dll**, lalu pilih **Copy** (atau tekan `Ctrl + C`).

### 3. Masuk ke Folder Instalasi Photoshop CS6

- Buka **File Explorer** dan arahkan ke folder instalasi Photoshop CS6.
- Secara default, lokasinya berada di:
  ```
  C:\Program Files\Adobe\Adobe Photoshop CS6 (64 Bit)
  ```


### 4. Paste dan Replace File amtlib.dll

- Di dalam folder instalasi Photoshop, Anda akan melihat file **amtlib.dll** yang asli (file validasi lisensi Adobe).
- **Paste** file crack yang sudah Anda copy tadi ke folder ini (klik kanan → **Paste**, atau tekan `Ctrl + V`).
- Ketika muncul dialog konfirmasi **"Replace file?"**, klik **"Copy and Replace"** atau **"Yes"**.


:::danger

Backup File Asli (Opsional) Jika Anda ingin bermain aman, sebelum mereplace file `amtlib.dll` yang asli, Anda bisa **rename** file tersebut menjadi `amtlib.dll.bak` sebagai backup. Namun, ini tidak wajib dilakukan.
:::

## Tahap 4: Memblokir Koneksi Photoshop.exe di Firewall

Setelah crack diterapkan, langkah selanjutnya adalah memblokir Photoshop agar tidak terhubung ke server Adobe untuk validasi lisensi online.

### 1. Buka Windows Defender Firewall

- Tekan `Windows + R` untuk membuka dialog **Run**.
- Ketik **firewall.cpl** lalu tekan **Enter**.
- Jendela **Windows Defender Firewall** akan terbuka.


### 2. Masuk ke Advanced Settings

- Di panel sebelah kiri, klik **"Advanced settings"**.
- Jendela **Windows Defender Firewall with Advanced Security** akan terbuka.


### 3. Buat Outbound Rule Baru

- Di panel sebelah kiri, klik **"Outbound Rules"**.
- Di panel sebelah kanan, klik **"New Rule..."**.


### 4. Pilih "Program" dan Klik Next

- Pada wizard **New Outbound Rule**, pilih **"Program"**, lalu klik **Next**.


### 5. Browse dan Pilih Photoshop.exe

- Pilih opsi **"This program path:"**.
- Klik tombol **Browse...**.
- Arahkan ke folder instalasi Photoshop CS6 dan pilih file **Photoshop.exe**:
  ```
  C:\Program Files\Adobe\Adobe Photoshop CS6 (64 Bit)\Photoshop.exe
  ```
- Klik **Open**, lalu klik **Next**.


### 6. Pilih "Block the Connection"

- Pada halaman **Action**, pilih **"Block the connection"**.
- Klik **Next**.


### 7. Terapkan Rule untuk Semua Profile

- Pada halaman **Profile**, pastikan ketiga opsi berikut tercentang:
  - **Domain**
  - **Private**
  - **Public**
- Klik **Next**.


### 8. Beri Nama Rule

- Pada halaman terakhir (**Name**), beri nama rule tersebut, misalnya:
  ```
  Adobe Photoshop CS6
  ```
- Anda juga bisa menambahkan deskripsi opsional seperti "Block Photoshop from connecting to Adobe servers".
- Klik **Finish**.


:::tip

Verifikasi Rule Setelah rule dibuat, Anda akan melihatnya muncul dalam daftar **Outbound Rules** dengan ikon "blocked" (tanda silang merah). Ini berarti Photoshop CS6 sekarang tidak bisa terhubung ke internet untuk validasi lisensi.
:::

## Tahap 5: Menjalankan dan Menguji Photoshop CS6

Setelah semua langkah selesai, saatnya membuka dan menguji Photoshop CS6.

### 1. Buka Adobe Photoshop CS6

- Cari **Adobe Photoshop CS6** dari menu Start Windows.
- Klik untuk membuka aplikasi.


### 2. Verifikasi Tidak Ada Notifikasi Trial

- Jika crack berhasil diterapkan, Photoshop akan terbuka tanpa menampilkan notifikasi "Trial period remaining" atau permintaan aktivasi.
- Anda dapat langsung menggunakan semua fitur Photoshop tanpa batasan.


### 3. Uji Coba Fitur Dasar

- Coba buat dokumen baru: **File → New**.
- Gunakan beberapa tools seperti **Brush**, **Text**, atau **Gradient** untuk memastikan aplikasi berfungsi dengan normal.

Jika semua berjalan lancar tanpa error, selamat - **instalasi Adobe Photoshop CS6 Anda telah berhasil!** 🎉

## Troubleshooting Umum

| Masalah | Penyebab | Solusi |
|---|---|---|
| File `amtlib.dll` terhapus saat instalasi | Antivirus mendeteksi crack sebagai malware | Nonaktifkan antivirus sebelum menyalin file crack, lalu aktifkan kembali setelah selesai |
| Photoshop crash saat dibuka | File crack tidak compatible atau corrupt | Download ulang file crack dari sumber terpercaya dan pastikan versi crack sesuai dengan Photoshop CS6 64-bit |
| Muncul notifikasi "Trial expired" | Crack belum diterapkan dengan benar | Ulangi **Tahap 3**: pastikan file `amtlib.dll` di-replace dengan benar di folder instalasi |
| Photoshop meminta aktivasi online | Firewall belum diblokir atau rule tidak aktif | Ulangi **Tahap 4** dan pastikan outbound rule untuk Photoshop.exe sudah dibuat dan aktif |
| Error "Configuration error" saat instalasi | File installer corrupt atau tidak lengkap | Download ulang file installer Adobe Photoshop CS6 yang lengkap |
| Photoshop sangat lambat atau lag | RAM tidak cukup atau komputer spesifikasi rendah | Tingkatkan RAM minimal 4 GB, tutup aplikasi lain saat menggunakan Photoshop, atau gunakan versi 32-bit jika RAM di bawah 4 GB |

## Tips Penggunaan Photoshop CS6

Setelah instalasi selesai, berikut beberapa tips untuk memaksimalkan penggunaan Photoshop CS6:

### 1. Atur Scratch Disk

- Masuk ke **Edit → Preferences → Performance**.
- Pilih drive dengan ruang kosong terbesar sebagai **Scratch Disk** (sebaiknya bukan drive sistem C: jika memungkinkan).
- Ini akan meningkatkan performa saat editing file besar.

### 2. Nonaktifkan Auto Update

- Buka **Edit → Preferences → General**.
- Nonaktifkan opsi **"Automatically Check for Updates"** untuk menghindari notifikasi update yang tidak diperlukan.

### 3. Install Plugin Tambahan

- Photoshop CS6 mendukung berbagai plugin pihak ketiga seperti **Nik Collection**, **Topaz Labs**, atau **Alien Skin** untuk efek tambahan.

### 4. Aktifkan GPU Acceleration (Jika Ada)

- Masuk ke **Edit → Preferences → Performance**.
- Centang **"Use Graphics Processor"** jika komputer Anda memiliki VGA card yang mendukung OpenGL.
