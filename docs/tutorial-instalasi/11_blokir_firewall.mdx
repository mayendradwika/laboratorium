# Cara Memblokir Aplikasi di Windows Firewall

Memblokir aplikasi melalui Windows Firewall adalah teknik yang sering digunakan untuk mencegah software tertentu terhubung ke internet. Hal ini berguna untuk berbagai keperluan, seperti mencegah validasi lisensi online pada software yang sudah di-crack, menghemat bandwidth, atau meningkatkan keamanan dengan memblokir aplikasi yang tidak perlu mengakses internet.

Panduan ini akan membantu Anda memblokir koneksi internet dari aplikasi tertentu menggunakan Windows Defender Firewall dengan langkah-langkah yang mudah dipahami.

:::info

Kapan Perlu Memblokir Aplikasi? - Software yang sudah di-crack agar tidak melakukan validasi lisensi online - Aplikasi yang terlalu banyak mengirim data telemetry - Game offline yang tidak memerlukan koneksi internet - Software lama yang memiliki vulnerability keamanan jika terhubung ke internet
:::

---

## Tahap 1: Membuka Windows Defender Firewall

Langkah pertama adalah mengakses pengaturan Windows Defender Firewall dengan Advanced Security.

### 1. Buka Windows Defender Firewall

Ada beberapa cara untuk membuka Windows Defender Firewall:

**Cara 1: Menggunakan Run Dialog**
1. Tekan `Windows + R` untuk membuka dialog Run.
2. Ketik **firewall.cpl** lalu tekan **Enter**.
3. Jendela Windows Defender Firewall akan terbuka.

**Cara 2: Menggunakan Control Panel**
1. Buka **Control Panel**.
2. Pilih **System and Security**.
3. Klik **Windows Defender Firewall**.

**Cara 3: Menggunakan Search**
1. Tekan tombol **Start** atau `Windows`.
2. Ketik **Firewall** di kolom pencarian.
3. Pilih **Windows Defender Firewall** dari hasil pencarian.

### 2. Masuk ke Advanced Settings

1. Setelah jendela Windows Defender Firewall terbuka, cari dan klik **Advanced settings** di panel sebelah kiri.
2. Jendela baru akan terbuka dengan judul **Windows Defender Firewall with Advanced Security**.

:::tip

Akses Cepat Anda juga bisa langsung membuka Advanced Settings dengan mengetik **wf.msc** di Run dialog (`Windows + R`).
:::

## Tahap 2: Membuat Outbound Rule Baru

Outbound Rule digunakan untuk mengontrol koneksi keluar dari komputer Anda ke internet. Dengan membuat rule untuk memblokir aplikasi tertentu, aplikasi tersebut tidak akan bisa mengirim data ke server eksternal.

### 1. Pilih Outbound Rules

- Di jendela **Windows Defender Firewall with Advanced Security**, perhatikan panel sebelah kiri.
- Klik **Outbound Rules** untuk melihat daftar rule yang mengatur koneksi keluar.

:::info

Perbedaan Inbound dan Outbound - **Inbound Rules** - Mengatur koneksi yang masuk ke komputer Anda dari luar - **Outbound Rules** - Mengatur koneksi yang keluar dari komputer Anda ke internet Untuk memblokir aplikasi agar tidak terhubung ke internet, kita gunakan **Outbound Rules**.
:::

### 2. Buat Rule Baru

- Di panel sebelah kanan, cari dan klik **New Rule...** (atau klik kanan di area kosong pada daftar Outbound Rules, lalu pilih **New Rule...**).
- Wizard **New Outbound Rule** akan terbuka.

## Tahap 3: Konfigurasi Rule

Sekarang kita akan mengatur rule untuk memblokir aplikasi tertentu.

### 1. Pilih Rule Type: Program

- Pada halaman pertama wizard (**Rule Type**), pilih **Program**.
- Klik **Next**.

Dengan memilih "Program", kita akan membuat rule yang spesifik untuk satu aplikasi tertentu berdasarkan lokasi file .exe-nya.

### 2. Pilih Program yang Akan Diblokir

- Pada halaman **Program**, pilih opsi **This program path:**.
- Klik tombol **Browse...** untuk mencari file executable (.exe) dari aplikasi yang ingin diblokir.

**Contoh lokasi file program umum:**
- Adobe Photoshop CS6:
  ```
  C:\Program Files\Adobe\Adobe Photoshop CS6 (64 Bit)\Photoshop.exe
  ```
- CorelDRAW X7:
  ```
  C:\Program Files\Corel\CorelDRAW Graphics Suite X7\Programs64\CorelDRW.exe
  ```
- MATLAB:
  ```
  C:\Program Files\MATLAB\R2021a\bin\win64\MATLAB.exe
  ```

- Setelah memilih file .exe yang tepat, klik **Open**.
- Path file akan muncul di kolom **This program path**.
- Klik **Next**.

:::tip

Cara Menemukan Lokasi File .exe Jika tidak tahu lokasi file .exe aplikasi: 1. Klik kanan pada shortcut aplikasi di Desktop atau Start Menu 2. Pilih **Open file location** 3. Anda akan dibawa ke folder tempat file .exe berada 4. Salin path folder tersebut untuk digunakan di Firewall
:::

### 3. Pilih Action: Block the Connection

- Pada halaman **Action**, pilih **Block the connection**.
- Klik **Next**.

Opsi ini akan memblokir semua koneksi yang dilakukan oleh aplikasi tersebut, baik melalui jaringan lokal maupun internet.

### 4. Pilih Profile: Semua Jaringan

- Pada halaman **Profile**, pastikan ketiga opsi berikut tercentang:
  - **Domain** - Untuk jaringan domain perusahaan/institusi
  - **Private** - Untuk jaringan rumah atau kantor yang terpercaya
  - **Public** - Untuk jaringan publik seperti WiFi cafe atau bandara
- Klik **Next**.

Dengan mencentang semua profile, aplikasi akan terblokir di semua jenis jaringan.

### 5. Beri Nama Rule

- Pada halaman **Name**, beri nama yang jelas dan mudah diingat untuk rule ini.

**Contoh nama rule:**
- `Blokir Adobe Photoshop CS6`
- `Blokir CorelDRAW X7`
- `Blokir MATLAB R2021a`

- (Opsional) Anda juga bisa menambahkan deskripsi pada kolom **Description**, misalnya: "Memblokir Photoshop agar tidak validasi lisensi online."
- Klik **Finish**.

Rule baru akan dibuat dan langsung aktif. Aplikasi yang Anda pilih kini tidak akan bisa terhubung ke internet.

## Tahap 4: Verifikasi dan Kelola Rule

Setelah rule dibuat, Anda bisa memverifikasi dan mengelolanya dari daftar Outbound Rules.

### 1. Cek Rule di Daftar

- Kembali ke jendela **Windows Defender Firewall with Advanced Security**.
- Klik **Outbound Rules** di panel kiri.
- Cari nama rule yang baru saja Anda buat di daftar.
- Rule yang memblokir koneksi akan memiliki ikon dengan tanda **silang merah** atau **stop sign**.

### 2. Menonaktifkan Rule Sementara

Jika sewaktu-waktu Anda ingin mengizinkan aplikasi terhubung ke internet tanpa menghapus rule:
1. Klik kanan pada rule tersebut.
2. Pilih **Disable Rule**.
3. Untuk mengaktifkan kembali, klik kanan lagi dan pilih **Enable Rule**.

### 3. Menghapus Rule

Jika ingin menghapus rule secara permanen:
1. Klik kanan pada rule tersebut.
2. Pilih **Delete**.
3. Konfirmasi penghapusan dengan klik **Yes**.

## Contoh Kasus Penggunaan

Berikut beberapa contoh praktis memblokir aplikasi di Firewall:

### Contoh 1: Memblokir Adobe Photoshop CS6

**Tujuan:** Mencegah Photoshop melakukan validasi lisensi online setelah di-crack.

**Langkah:**
1. Buat Outbound Rule baru.
2. Browse ke: `C:\Program Files\Adobe\Adobe Photoshop CS6 (64 Bit)\Photoshop.exe`
3. Block the connection.
4. Nama rule: `Blokir Adobe Photoshop CS6`

### Contoh 2: Memblokir Game yang Tidak Perlu Internet

**Tujuan:** Mencegah game single-player mengirim telemetry atau iklan online.

**Langkah:**
1. Buat Outbound Rule baru.
2. Browse ke file .exe game (contoh: `C:\Games\MyGame\game.exe`)
3. Block the connection.
4. Nama rule: `Blokir MyGame`

### Contoh 3: Memblokir Aplikasi Akuntansi atau ERP

**Tujuan:** Mencegah software akuntansi yang sudah di-crack melakukan cek lisensi.

**Langkah:**
1. Buat Outbound Rule baru.
2. Browse ke file .exe aplikasi (contoh: `C:\Program Files (x86)\CPSSoft\Accurate5 Enterprise\Accurate.exe`)
3. Block the connection.
4. Nama rule: `Blokir Accurate 5 Enterprise`

## Troubleshooting Umum

| Masalah | Penyebab | Solusi |
|---|---|---|
| Rule sudah dibuat tapi aplikasi masih bisa akses internet | Rule tidak aktif atau salah file .exe | Pastikan rule dalam keadaan **Enabled** dan path file .exe sudah benar |
| Tidak bisa membuat rule baru | Tidak ada hak akses Administrator | Jalankan Windows sebagai Administrator atau login dengan akun Administrator |
| Aplikasi error setelah diblokir | Aplikasi memerlukan koneksi internet untuk berfungsi | Disable rule atau hapus rule jika aplikasi memang memerlukan koneksi |
| Terlalu banyak rule sehingga sulit dikelola | Tidak ada sistem penamaan yang jelas | Gunakan nama rule yang konsisten dan deskriptif |

## Tips dan Best Practices

### 1. Gunakan Nama Rule yang Jelas

Berikan nama rule yang mudah dipahami dan mencerminkan aplikasi yang diblokir. Hindari nama generik seperti "Rule 1" atau "Block App".

### 2. Tambahkan Deskripsi

Manfaatkan kolom deskripsi untuk menjelaskan alasan pembuatan rule, misalnya "Blokir validasi lisensi" atau "Menghemat bandwidth".

### 3. Review Rule Secara Berkala

Hapus rule yang sudah tidak digunakan agar daftar tetap rapi dan mudah dikelola.

### 4. Backup Rule (Untuk Administrator)

Jika mengelola banyak komputer lab, export rule Firewall agar bisa di-import ke komputer lain dengan cepat:
1. Klik kanan **Windows Defender Firewall with Advanced Security** di panel kiri atas.
2. Pilih **Export Policy...**.
3. Simpan file .wfw yang dihasilkan.

---

> **Catatan untuk Asisten Laboratorium:**
> Pastikan semua aplikasi yang menggunakan crack atau lisensi non-standar di komputer lab sudah diblokir melalui Firewall untuk mencegah validasi online yang bisa merusak aktivasi. Buat daftar rule standar dan export sebagai policy file agar bisa diterapkan ke semua komputer secara seragam. Untuk software legal dengan lisensi resmi, jangan blokir koneksi internet agar update dan fitur cloud tetap berfungsi.
