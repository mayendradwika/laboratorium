## Tahap 3: Instalasi IBM SPSS

### 1. Welcome Screen

Installer IBM SPSS akan terbuka. Klik **Yes** atau **Next**

### 2. Pilih "Install IBM SPSS Statistics"

Pada menu utama installer, pilih:
- **Install IBM SPSS Statistics** (bukan trial atau update)

### 3. License Agreement

- **I accept** semua license agreement yang muncul
- Klik **Next**

### 4. Installation Type

- Pilih **Typical** atau biarkan default
- Klik **Next**

### 5. Destination Folder

- Biarkan lokasi default:
  ```
  C:\Program Files (x86)\IBM\SPSS\Statistics\26
  ```
- Klik **Next**

### 6. Ready to Install

- Klik **Install**
- Tunggu proses instalasi (10-20 menit)

### 7. Finish - JANGAN BUKA SPSS DULU

Setelah instalasi selesai:
- Pilih **No** jika ditanya "Launch SPSS now"
- Atau **jangan centang** "Run SPSS Statistics"
- Klik **Finish**

Penting Jangan buka SPSS dulu. Kita perlu apply crack terlebih dahulu.

## Tips Penggunaan SPSS

### 1. Import Data

SPSS mendukung berbagai format:
- **Excel** (.xls, .xlsx) - paling umum
- **CSV** (.csv)
- **SPSS** (.sav)
- **Text** (.txt, .dat)

Import via: **File → Open → Data**

### 2. Analisis Dasar

Menu analisis utama di **Analyze**:
- **Descriptive Statistics** → Frequencies, Descriptives
- **Compare Means** → T-test, ANOVA
- **Correlate** → Bivariate, Partial
- **Regression** → Linear, Logistic

### 3. Output Navigator

Hasil analisis muncul di **Output Navigator**. Export hasil:
- **File → Export** → Word, PDF, Excel

### 4. Syntax Editor

Untuk analisis berulang, gunakan Syntax:
- **File → New → Syntax**
- Tulis perintah SPSS
- Jalankan dengan **Run → All**
